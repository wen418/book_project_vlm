# 按钮 few-shot 样例说明

四种按钮组合现已各有 3 张图片，并已写入 `manifest.json`：

1. `up_off&down_off*.jpg`：上键灭、下键灭；
2. `up_on&down_off*.jpg`：上键亮、下键灭；
3. `up_off&down_on*.jpg`：上键灭、下键亮；
4. `up_on&down_on*.jpg`：上键亮、下键亮。

这里的“按下”以红色背光/边框点亮为准，不以手指接触为准。

真机测试前仍需补充反光、过曝、遮挡、运动模糊等困难样本；无法可靠识别的样本应让模型输出 `null`，不要把它们错误标成亮或灭。评测集应按视频片段划分，不能把同一段视频的相邻帧同时放入 few-shot 和测试集。
