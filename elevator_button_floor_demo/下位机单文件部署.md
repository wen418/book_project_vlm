# 下位机只复制一个 Python 文件

更新日期：2026-10-15。

下位机现在只需新增 **`elevator_button_floor_main.py`**，放到已有 `book` 目录，与原有 `api.py` 同级。流程、结果校验、限位和默认参数均已包含在这个文件中，不需要再上传共享模块、JSON 配置、图片、测试文件或整个压缩包。

继续使用下位机原有 ROS、机器人 SDK、`book/api.py`，没有把整个机器人运行环境打包进这个文件。

输出会明确写明“参数来源：本文件 DEFAULT_CONFIG（内置）”。

## 3. 参数直接在这个文件顶部修改

```bash
nano elevator_button_floor_main.py
```

顶部 `DEFAULT_CONFIG` 中包含按钮点、原点、进出梯点、头部角度、等待时间等。现在是 **Python 字典**，布尔值使用 `True` / `False`，空值使用 `None`。

- 看屏幕的初始候选：`'floor': {'yaw': -20.0, 'pitch': -10.0}`。
- 按钮点：`x=0.110`、`y=0.976` 米，X 正负号仍需现场核对。
- 现场核对完成后，将 `'calibrated': False` 改为 `'calibrated': True`。

未传 `--config` 时不会自动读取旁边的 JSON。若确实想复用之前的外部配置，可以显式传入：

```bash
python3 elevator_button_floor_main.py --config /完整路径/elevator_button_floor_demo.json --mock
```

## 5. 下位机分步执行

只读连接检查：

```bash
python3 elevator_button_floor_main.py --check-services
```

仅测试转头，不移动底盘：

```bash
python3 elevator_button_floor_main.py --head-only floor --estop-ready
python3 elevator_button_floor_main.py --head-only door --estop-ready
```

确认点位和视角、更新内置 `calibrated` 后，启动完整演示：

```bash
python3 elevator_button_floor_main.py --run --preflight-confirmed --perception-confirmed --estop-ready
```

不要同时执行旧的进出梯程序。运行记录保存在这个脚本旁的 `logs` 目录。本次文件简化不改变原有运行前提、物理急停要求、目标 20 楼和机器人不自动按键的行为。
