## 3 当前流程与回退方案

厅外原点→按钮观察点→等待下行按钮点亮→头部恢复看门→回原点或较近观察点→等门完整打开→进梯并按inside朝向转身→看右上方屏幕等目标楼层→看门并用新图确认全开→出梯。机器人不自动按厅外或梯内按钮，不控制电梯，不自动换地图；单改目标楼层也不会把下行按钮识别改成上行。

| 方案 | 行为 |
| --- | --- |
| baseline | 原路线对照，允许回退导航转向；原demo默认 |
| origin_no_turn | 量化默认；按钮点回原origin时禁转，保持出发实测方向，无需新坐标 |
| reduced_backtrack | 较近观察点默认(-0.901m,0.004m,6°)，回退段同样禁转，可不传entry-pose |

用户已确认截图为 **(-901mm,4mm,朝向6°)**，第三个不是高度，不再要求确认或按毫米换算。center_shift门中心平移已取消，因为看不全门。reduced_back是错误参数名，正确为reduced_backtrack。

禁转只作用按钮点返回观察点这段，其他导航和进梯后的原有转身保留。回退前实测朝向与origin.theta偏差不得超过10°，目标theta保持出发实测方向而非强制6°；回退全程采样最大角变化不得超过5°且反馈有效。可能减少转向时间，但不能预设一定更快，也不保证路径为直线后退。

## 5 采样频率和计时口径

VLM最多每秒一次请求，每次取当前阶段的新鲜最新帧，不对相机每帧调用模型。同步云端推理超过1秒时实际结果频率更低，不能用每秒心跳假充新识别。门与按键的连续核验图另按约10Hz保存，实际间隔以源时间戳为准。

目前按用户“全部统一1Hz”的要求，配置和启动代码都有固定值，**只改YAML或JSON不会改变有效频率**：

| 项目 | 配置及覆盖 |
| --- | --- |
| 门 | 原门工程ros1/elevator_vlm_api_perception/config/perception.yaml的inference_hz:1.0；同包launch/elevator_vlm.launch再次固定1.0 |
| 按键楼层 | 新工程params/elevator_button_floor_demo.json的extra_perception.inference_period:1.0秒；elevator_extra_perception.py的--inference-hz默认及choices固定1.0并覆盖JSON |
| 启动检查 | elevator_demo_launcher.py要求门ROS参数和附加ready消息均1Hz，拒绝复用旧频率节点 |
| 连续核验图 | elevator_quantification.py的DOOR_FRAME_INTERVAL_S=0.1，门与按键共用 |

若用户下一轮要求自由调频，应集中配置并移除对应覆盖、同步就绪检查，不能只改一个数后宣称生效。

自动计时包括等门到识别、推理调用链、识别到发令、API调用、发令到实测起步、起步到inside导航到点及稳定等待；另测回退导航、稳定等待、最大朝向变化。按钮分首次有效点亮识别、连续确认及两者等待。自动耗时使用下位机同一单调时钟，不跨机相减。

人工“物理全开/点亮→识别”用相机ROS源时间与下位机确认ROS时间相减。同一ROS Master不保证跨机同步；未独立确认同步时只是估计，不能宣称总体0.1秒精度。latency_ms含网络解析等调用链，不是GPU纯前向耗时。

实测起步用/jarvis/pose的新鲜静止基线：平移1.5cm或旋转0.03rad，连续三帧确认后回填第一帧越阈值时刻。不是精确电机首动瞬间。旧/tracked_pose无发布者；局部/odom、/jarvis/odom朝向与地图不同，不直接替代map位姿。inside到点反馈是程序进梯完成口径，不是独立视觉测得整机跨门槛。

**时间核验**：door_review.html或button_review.html可切换对象。无需每帧标，推荐只选最后未全开和第一张完全打开两帧；按键同理选最后未亮和第一张点亮。自动读取时间并给延迟范围，不让用户手抄时间戳。只选第一张全开也能算到该帧的差值，但无两帧物理时间范围。开头已全开/已亮、未拍到变化或遮挡看不清时选无法确定，不把第一张看见的图当首次变化。半开和正在开门都不是全开；负延迟据实保留并检查误识别或时钟偏差。

导出trial_review.json覆盖同轮原文件；实际挡门、进梯成功和备注也在此填。门与按键标记可一起导出；继续以前标记时先导入上次文件，避免旧网页覆盖进度。

**识别正确率**：点击报告“看图核验识别对错”或打开labels_review.html。左看源图、右点真实状态，程序自动判断对错；有对象/未标注/正确错误筛选、自动下一张、方向键、1/2与U快捷键、备注及图片放大。逐条标实际识别结果帧，不用标约10Hz全部连续图。可分次导出，未标注不算正确；缺图或坏图时不猜确定真值。

| 画面真值 | labels.csv的ground_truth |
| --- | --- |
| 门完全关闭 / 完全打开 | true / false，字段door_closed |
| 门半开、开关中或看不清 | null |
| 下行按钮点亮 / 未亮 | true / false，字段button_lit |
| 实际显示楼层 | 整数，例如15，不按目标楼层猜 |
| 人工无法判断 | null，区别于模型未作答abstained |
| 尚未核验 | 留空，区别于null和false |

页面导出labels.csv覆盖同轮原文件。分次标注可导入上次CSV；检查编号、模式、源图和预测一致，拒绝串轮；原手填标注会加载，格式错误可重新点选修复。不以高置信度认定正确。
